# Checklist : créer et livrer un site avec Hostinger et l'IA

## 1. Le compte Hostinger
- [ ] Ouvrir le lien Hostinger de la description, puis « Voir les packs »
- [ ] Choisir l'offre **Unlimited** (sites web illimités)
- [ ] Durée : **12 mois minimum** (c'est le prix mensuel le plus bas)
- [ ] Ajouter le code **KAMARA7** (réduction supplémentaire, valable sur le premier achat)
- [ ] Paiement et création du compte

## 2. Le site
- [ ] Choisir le mode de création **IA**
- [ ] Coller le prompt (voir `01-prompt-site.md`) et lancer
- [ ] Répondre aux questions de l'IA (ex. réservation en ligne : oui seulement si le client en a besoin)
- [ ] Vérifier chaque page : accueil, services, galerie, à propos, contact, carte

## 3. Le vrai contenu du client
- [ ] Remplacer les images générées par **les vraies photos** du client
- [ ] Vraies prestations, vrais prix
- [ ] Vraie adresse, vrai téléphone, vrais horaires
- [ ] Avis clients réels (pas d'avis inventés)

## 4. Les modifications
- [ ] Une demande à la fois dans la zone de chat (voir `02-prompts-modification.md`)

## 5. La mise en ligne
- [ ] Cliquer sur **Publier** : le site est en ligne sur une URL temporaire
- [ ] **Connecter un nom de domaine personnalisé** (ex. nomduclient.com)
- [ ] Si le domaine appartient déjà au client : lui demander les accès nécessaires pour le connecter
- [ ] Tester le site sur téléphone et sur ordinateur
