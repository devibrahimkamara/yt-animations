# Le prompt du site (vidéo Hostinger)

## Le prompt exact de la vidéo

C'est le prompt collé dans le créateur de sites IA d'Hostinger (mode IA). Je l'ai fait générer par Claude avec des informations factices.

```
Crée un site web professionnel en français pour une entreprise de customisation automobile basée à Marseille. L'entreprise propose des services de personnalisation de véhicules : covering, jantes, kits carrosserie, intérieur sur mesure, et tuning.

Nom de l'entreprise : [nom de la société]
Ton : professionnel, dynamique, orienté performance et style, inspirant confiance et savoir-faire artisanal.

Structure :
- Accueil avec image forte d'un véhicule customisé et accroche sur l'expertise de l'entreprise
- Page "Services" détaillant chaque prestation (covering, jantes, carrosserie, intérieur, tuning)
- Galerie photos/portfolio des réalisations avant/après
- Page "À propos" présentant l'atelier, l'équipe et leur expérience
- Page "Contact" avec formulaire, adresse à Marseille, numéro de téléphone et carte Google Maps
- Section avis clients / témoignages
- Bouton d'appel à l'action pour devis gratuit

Design : esthétique sombre et racée (noir, gris anthracite avec accents rouge ou orange), typographie moderne et impactante, mise en page inspirée des sites automobiles premium/tuning.

Fonctionnalités : galerie photo optimisée, responsive mobile, formulaire de devis, SEO local (Marseille).
```

## La version à adapter à ton client

Remplace tout ce qui est entre [CROCHETS].

```
Crée un site web professionnel en français pour [TYPE D'ENTREPRISE] basée à [VILLE]. L'entreprise propose : [LISTE DES SERVICES OU PRODUITS].

Nom de l'entreprise : [NOM]
Ton : [3 À 5 ADJECTIFS, ex. professionnel, chaleureux, premium, rassurant].

Structure :
- Accueil avec [IMAGE FORTE : ex. le produit phare, l'équipe, le lieu] et une accroche sur [LE POINT FORT DE L'ENTREPRISE]
- Page "Services" détaillant chaque prestation ([PRESTATION 1], [PRESTATION 2], [PRESTATION 3])
- Galerie photos / réalisations [ex. avant/après]
- Page "À propos" présentant [L'HISTOIRE, L'ÉQUIPE, L'EXPÉRIENCE]
- Page "Contact" avec formulaire, adresse à [VILLE], numéro de téléphone et carte Google Maps
- Section avis clients / témoignages
- Bouton d'appel à l'action pour [OBJECTIF : devis gratuit, réservation, appel, achat]

Design : [AMBIANCE : ex. sombre et racée, claire et naturelle], couleurs [COULEUR 1, COULEUR 2, COULEUR D'ACCENT], typographie [moderne / élégante / ludique], inspirée des sites [SECTEUR] haut de gamme.

Fonctionnalités : [ex. galerie optimisée, responsive mobile, formulaire de devis, réservation en ligne, SEO local ([VILLE])].
```

## Faire écrire le prompt par Claude (ou ChatGPT)

Si tu pars des notes de ton client, demande à l'IA d'écrire le prompt pour toi :

```
Écris-moi un prompt complet pour le créateur de sites IA d'Hostinger. Le site est pour [NOM DE L'ENTREPRISE], [TYPE D'ENTREPRISE] à [VILLE]. Voici les infos du client : [COLLE ICI SES NOTES, SERVICES, HORAIRES, ADRESSE, STYLE SOUHAITÉ].
Le prompt doit préciser : le ton, la structure page par page (accueil, services, galerie, à propos, contact avec carte, avis clients, appel à l'action), le design (ambiance, couleurs, typographie) et les fonctionnalités (responsive mobile, formulaire, SEO local).
```
