# Modifier le site avec un prompt

Tout se fait dans la zone de chat du créateur IA (« Demander des changements »).

## Le prompt exact de la vidéo

```
J'aimerais que tu changes les couleurs principales, là on est sur du noir/rouge. J'aimerais du noir/blanc.
```

Résultat : tout ce qui était rouge passe en blanc, le reste du site ne bouge pas.

## D'autres modifications utiles

```
Remplace les images de la galerie par les photos que je t'envoie, dans cet ordre : [PHOTOS].
```
```
Mets à jour la page Contact : adresse [ADRESSE], téléphone [NUMÉRO], horaires [HORAIRES], e-mail [E-MAIL].
```
```
Ajoute une section « Tarifs » sous les services, avec ces prix : [PRESTATION : PRIX].
```
```
Ajoute une fonctionnalité de réservation en ligne avec choix d'une date et d'une heure.
```
```
Le site a un problème : [DÉCRIS LE BUG, LA PAGE CONCERNÉE]. Corrige-le sans rien changer d'autre.
```

Astuce : demande une seule chose à la fois et précise « sans rien changer d'autre ». L'IA modifie alors uniquement ce que tu demandes.
