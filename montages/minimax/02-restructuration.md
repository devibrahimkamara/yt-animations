1. la preuve visible dès 0:00 ;
2. la Carte du tuto ;
3. les **ajouts entre les démonstrations** (cartons, teasers, showcases) ;
4. l'habillage **par-dessus** les démonstrations longues (installation, Canvas, étape 3) ;
5. la fin, qui n'est pas une démonstration.

## 5. Limite propre à cette vidéo

Le corps (0:36–8:48) est une capture d'écran avec ta webcam **déjà incrustée** en médaillon. Conséquences :
- pas de vrai retour en face cam plein écran pendant les démos ;
- pas de médaillon qui se déplace ou s'efface.

On compense par les cartons d'étape, la Carte du tuto, les showcases ajoutés entre les démonstrations et les zooms qui excluent le médaillon du cadre.
