# 6 · Checklist : de l'idée à la première vente

**Le produit (Claude)**
- [ ] Demander des idées de produits **avec recherches sur Internet** (ressource 1)
- [ ] Choisir une idée liée à ton expérience ou à ce que ton audience cherche
- [ ] Faire créer l'e-book complet avec des **infos réelles** (ressource 2)
- [ ] Faire vérifier l'e-book par l'IA, puis le relire (ressource 3)
- [ ] Télécharger le PDF

**La page de vente (Hostinger)**
- [ ] Prendre **Hostinger Ecommerce (Pack Growth, 12 mois)** + l'option **Créateur de site IA**, avec le code **KAMARA7** (78,83 € TTC la 1re année au 11/10/2026)
- [ ] Créer un nouveau site → « Décrivez-le, nous le construisons » → mode **IA**
- [ ] Nom de domaine temporaire pour commencer
- [ ] Faire écrire le prompt de la page par Claude (≤ 2 000 caractères) (ressource 4)
- [ ] Mettre ton nom, tes photos et tes résultats sur la page (ressource 5)
- [ ] Petites retouches : « Sélectionner et modifier » (0 crédit)
- [ ] Vérifier la version mobile et le bouton d'achat
- [ ] Ajouter l'e-book comme **produit numérique** dans Hostinger Ecommerce et activer les paiements (0 % de frais)
- [ ] Publier, puis connecter ton propre nom de domaine

**Les clients**
- [ ] Contenu (YouTube, Instagram, TikTok) : gratuit mais long terme
- [ ] Publicité payante : commencer par Facebook Ads
