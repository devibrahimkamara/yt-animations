# 3 · Faire vérifier l'e-book par l'IA (avant de le vendre)

Dit à l'oral dans la vidéo (non tapé à l'écran) ; version prête à copier :

```
Relis le document que tu m'as créé et compare-le aux informations disponibles sur Internet.
Rassure-moi : toutes les informations présentes dans cet e-book sont-elles réelles ?
Liste chaque chiffre ou affirmation que tu n'as pas pu vérifier, avec la source que tu as trouvée ou « non vérifié ».
```

Si tu n'es pas expert du sujet, ne saute jamais cette étape.
