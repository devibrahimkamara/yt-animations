# Brief Higgsfield Ads Studio (reçu le 15/10/2026)

Usage interne uniquement : le brief ne doit pas apparaître dans la vidéo.

## Exigences vidéo (checklist structure)
- Vidéo dédiée de 6 min et plus, workflow montré sur le site higgsfield.ai
- **Static Ads** : import du site (ou marque manuelle) → revue du brand kit → choix des produits → nombre d'ads et devis en crédits → créas finies
- **Ad Multiplier** : vidéo de référence (upload ou preset) → crop/trim → images de référence (optionnel) → prompt OU hook/CTA → résolution et devis en crédits → résultat fini
- Montrer que le mode General Prompt et le mode Hook/CTA s'excluent (activer l'un coupe l'autre, le texte est gardé)
- Résultats réels uniquement, pas de cartes de chargement présentées comme résultats
- **Côte à côte source / résultat** pour Ad Multiplier
- Laisser le temps de lire le texte des static ads
- **À dire** : Ads Studio couvre les ads statiques ET les variations vidéo au même endroit ; on voit le coût en crédits avant de cliquer sur Generate
- Angles : une ad axée bénéfice, une axée problème, une axée situation
- Pas de logos, marques ou personnages tiers (marque à soi, fictive ou autorisée)

## Déroulé suggéré
1. Hook : ouvrir sur un résultat fini (lot de static ads ou comparaison source → résultat)
2. Démo Static Ads
3. Explication des angles
4. Démo Ad Multiplier
5. Côte à côte final : ce qui a changé, ce qui est resté
6. CTA : « Ouvre Higgsfield Ads Studio, ajoute ton site ou ta meilleure pub vidéo… lien en description »
