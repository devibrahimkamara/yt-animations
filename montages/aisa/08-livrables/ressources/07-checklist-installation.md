# Checklist d'installation (étape 2)

1. Créer ton compte sur **aisa.one** (lien en description).
2. **Choisir un plan** dans *Billing* : Pay as you go (sans abonnement), Builder (39 $/mois) ou Team (200 $/mois). Pour tester, Pay as you go suffit.
3. **Ajouter des crédits** (*Add credits*) : prévois au moins 15 $ : reproduire toute la vidéo coûte environ 11,70 $ d'appels (1,29 + 10,17 + 0,24).
4. Installer **Claude Code version desktop** : cherche « Claude Code desktop » et télécharge la version Mac ou Windows. Vérifie que tu es bien dans l'onglet **Code**, pas dans le chat.
5. Créer un **dossier par projet** (ex. `audit IA`) et le sélectionner dans Claude Code.
6. Lancer le **prompt 1** pour connecter AIsa, avec Sonnet 5, effort Medium, mode Accept edits.
7. **Redémarrer Claude Code**, puis lancer les prompts 2 à 5.
