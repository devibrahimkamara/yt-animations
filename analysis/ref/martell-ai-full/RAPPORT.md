#### [CAM3] Faux/vrai multicam à 3 axes + plongée — visuel-cadrage
- Famille Ibrahim : 1 (zooms) — la variante « changement d'axe » plutôt que zoom
- Exemples : 0:04.9→0:07.2→0:08.0 ; 5:20 (3/4 gauche) → 5:33 (face) ; 9:20 → 9:21 ; 11:44 → 11:46 → 11:51
- Fréquence : 151 plans visage, changement d'axe à presque chaque coupe (1 / 4–6 s dans le corps)
- Description : 4 positions fixes. (a) Face large centrée (visage h ≈ 0,19–0,21, cx 0,49–0,50), plante à gauche, livres bleus à droite ; (b) 3/4 gauche serré (h ≈ 0,20–0,22, cx 0,41–0,44 → visage sur le tiers gauche, mur bois chaud en fond) ; (c) face serré (h ≈ 0,24–0,34) ; (d) plongée zénithale sur le tableau blanc. Les sauts mesurés vont de ×0,64 à ×2,0 de taille de visage. Arrière-plan très flou (grande ouverture), lumière chaude latérale, mur bois.
- Fonction rétention : « quelque chose change toutes les 3–5 s » sans graphisme ; masque toutes les coupes de respiration (jump cuts invisibles).
- Pertinence Ibrahim : 3 — c'est le levier n°1 pour sa partie face cam, faisable avec un seul plan 1080p (recadrages 100 / 120 / 115 % décentré).
- Reproduction Remotion : `<FauxMulticam>` qui lit une liste `[{start,end,frame:'wide'|'tight'|'side'}]` et applique `scale` + `translateX` ; alterner automatiquement à chaque coupe de silence. Difficulté faible.

#### [ZOOM] Push-in ponctuels (rapides dans le hook, lents ailleurs) — visuel-cadrage

## 5. Son

**Voix** : sèche, très en avant, dynamique stable ; p90 médian −18,4 dB contre −56,8 dB pour la piste hors-voix (**écart 39 dB**). Respirations et blancs coupés (197 mots/min tenus 18 min). Aucun effet sur la voix (pas d'écho/réverb), même sur les punchlines.

**Musique** : elle n'est **jamais un tapis**. Le fond hors-voix reste à −55/−63 dB minute après minute (le plus bas : minutes 5–8, −61/−63 dB → c'est aussi la zone la plus « parlée »). 14 passages audibles seulement :
- 10 **stings** de 2–4 s aux transitions (0:00, 0:40, 0:52, 2:03, 2:16, 3:18, 4:27, 14:22, 15:26, 16:59) — presque toujours empilés sur un whoosh fort ;
- un seul **lit musical** continu : 16:41–16:57 (−45 dB), sous le dernier prompt tapé, qui prépare la conclusion ;
- le sting le plus fort (−19 dB) ouvre la vidéo à 0:00.

**SFX** : sur 331 détections automatiques, ~180 « impact/boom » courts sont des plosives mal séparées (ils suivent les mots « but », « the », « I »… et se densifient pendant les passages de parole rapide, ex. 10:15–10:45 ou 13:45–14:10 où l'image est un plan fixe). Restent ≈ **70 vrais SFX** :
- **whoosh/riser longs** (~11, +23 à +34 dB) → uniquement aux entrées de chapitre, cartes-titres et scènes motion ;
- **swooshs courts** (~25) → apparition de panneaux, lower-thirds, cartes, barres de graphique ;
- **pops** (~15) → pastilles, puces, UI ;
- **aucun « impact » franc sur les mots-clés** une fois le hook passé : l'emphase passe par l'image (sous-titre cinétique, zoom), pas par un boom.

**Placement** : 90 détections à < 0,6 s d'une coupe ; pour les vrais SFX la règle est « le son annonce l'image » (whoosh qui démarre 0,3–1 s avant l'insert). Répartition très inégale : dense dans les 4 premières minutes (motion design riche), quasi muette de 15:50 à 17:50 (sauf 16:59) — la fin repose sur la voix.
